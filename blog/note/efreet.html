トライ木がモナドになることについて

Efreet型

data Efreet f x = x :> Maybe (f (Efreet f x))
    deriving Functor

instance Functor f => Monad (Efreet f) where
    return a = a :> Nothing
    (a :> rest) >>= k = case rest of
        Nothing -> k a
        Just fma -> graft (k a) (fmap (>>= k) fma)

-- `graft mx fmy` replaces every leaf of mx (`x :> Nothing`) with
-- `x :> Just fmy`
graft :: Efreet f x -> f (Efreet f x) -> Efreet f x
graft mx fmy = case mx of
    x :> Nothing -> x :> Just fmy
    x :> (Just fmx) -> x :> Just (fmap (\mx' -> graft mx' fmy) fmx)

トライ木 Trie c x

トライ木は以下のようなデータ構造だ。

data Trie c x = Trie x (Map c (Trie c x))

これは頂点にx型の値、辺にc型の値がラベル付けされた木構造である。 (ここにトライ木のより丁寧な説明と図)

Trie c と同型な関手がEfreetを使って次のように書ける。 つまり、Trie cもモナドとみなすことが可能である。

Trie c x
  ~ (x, Map c (Trie c x))
  ~ (x, Maybe (NonEmptyMap c (Trie c x)))

Trie c x ~ Efreet (NonEmptyMap c) x

ここで、通常のMapから空なMapを除外した型を NonEmptyMapとおいた。

モナドとしてのTrie c x は 何を表すのか？

Trie c x は「cをアルファベットとする_prefix-closed finite language_ s と、その各元に対するx型の値の割当s -> x」 を保持するデータ構造と考えられる。

  • 言語(language)とは文字列の集合を意味する。また、言語Lの要素である文字列をLの語(word)とよぶ。

  • 有限言語(finite language)は、有限個の語からなる言語である。

  • ある言語Lがprefix-closedであるとは、

    1. Lは空文字列ε, ε = ""を含む
    2. xがLに含まれる語のとき、xの任意の接頭辞(prefix)もLに含まれる

    を満たすことである。例えば、

    • 言語L = ["", "a", "aa", "ab", "abc"] はprefix-closedである。実際、 Lの語"abc"のprefix"", "a", "ab", "abc"はどれもLに含まれている。

    • 一方、言語L' = ["", "a", "aa", "ab", "abcde"] はprefix-closedでない。 "abcde"のprefixである"abc"がL'に含まれていない。

    • 空集合∅はprefix-closedでない。prefix-closed言語は少なくともεを含まなければならない。

Prefix-closed languageの(半順序”xはyの接頭辞である”に関する)極大元は、 接頭符号(prefix code)という言語になっている。接頭符号は(1)空でない言語で(2)どの語も別の語の接頭辞になっていないものである。

接頭符号の語をいくつか結合して長い文字列Sを作ったとき、もとの語に分解する方法は一意であり、更にこのSの先頭から、Sの接頭辞になっている語を切り出していくという方法で分解が得られる。

例: c={0,1}, A={000, 001, 01, 1} は接頭符号

0000011111 は [000, 001, 1, 1, 1, 1] と一意に分解される

例: c={0,1}, A={00, 01, 010, 1} は接頭符号でない

01 は 010 の接頭辞になっている。 01001 は [01, 00, 1] か [010, 01] で曖昧である

例: c={0,1}, A={0, 01, 011} は接頭符号でない 分解は一意だが、接頭符号ではない。 0 は 01 の接頭辞になっている

  • 接頭符号は辺にc型のラベルが付いた木で表せる

[図]

  • Trie c x は、c型の”既知の文字”とx型の”変数記号”が交互に並んだ接頭符号

[図]

  • pure x :: Trie c x は、ルートしか無い木で、ルート頂点にxのラベルが付いている。

  • join :: Trie c (Trie c x) -> Trie c x は、各頂点vのラベルとして存在するt :: Trie c x をその場に展開して、 vの子要素たちfmx :: Map c (Trie c x) を再帰的に fmap join で展開した結果を t の葉すべてにgraftで繋げるという操作で木を作る。
