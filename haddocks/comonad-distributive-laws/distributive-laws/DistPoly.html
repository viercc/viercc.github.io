Laws:

(Q1) q x y (x :&: id) = y :&: id
(Q2) q x x dir = dir
(Q3) q x y (x'' :&: (g . f)) = (y'' :&: (qg . qf))

forall f :: cat x x' g :: cat x' x'' where (y' :&: qf) = q x y (x' :&: f) (y'' :&: qg) = q x' y' (x'' :&: g) > (Q4) q y z (q x y dir) = q x z dir
