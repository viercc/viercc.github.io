-- | Type equipped with left semigroup action.
-- 
-- 'act' must satisfy the following equation.
--
-- > s1 `act` (s2 `act` x) === (s1 '<>' s2) `act` x
--
-- Additionally, if `s` is a @Monoid@, the following equation must be satisfied too.
--
-- > mempty `act` x === x
-- 
-- If `s` is a @Group@, it follows that
--
-- > inv s1 `act` (s1 `act` x) === x
-- > s1 `act` (inv s1 `act` x) === x
--

-- | @Torsor g x@ is a type @x@ equipped with /free/ and /transitive/ left action
--   of a group @g@.
-- 
-- For an @Action g x@, it is called /transitive/ if every equation
--
-- > x = g `act` y
-- 
-- about @g@ has a solution. It is called /free/ if no such equation has multiple solutions
-- at a time. A /free transitive/ action therefore has a unique solution @g@ for every
-- combination of @x, y@.

-- @'difference' x y@ method, which gives the unique solution @g@ of @x = g `act` y@.
